# Stardust checkpoint backup

Preserve all existing user-directed research, verification, source-integrity and campaign
gates. At a natural completed, audited Git checkpoint, follow `STARDUST_SYNC.md` to
record the exact-commit audit receipt for the independent private GitHub synchronization.
Never approve unfinished work or replace a full build, axiom audit or public-type review
with a sync receipt. The Windows scheduler backs up existing commits every 30 minutes;
it does not commit work or require Codex to be running. Keep `.lake/stardust-sync` and
its referenced scanner when cleaning unrelated caches. No additional agent delegation
is required by these instructions.
